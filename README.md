MOD: Finals Week - ate 8 players
=================================

HOW TO INSTALL
On Steam, right-click on "Finals Week: Cool"
Manage > Explore local files.

Open the folder: CopyGirls\Content\Paks
Copy the file "CopyGirls-Windows_MorePlayers_P.pak" to this folder (next to CopyGirls-Windows.pak). DO NOT delete or replace anything.

Open the game normally.

HOW TO REMOVE
Delete the CopyGirls-Windows_MorePlayers_P.pak file from this folder.

NOTES
The person who creates the room (host) MUST have the mod. It is recommended that everyone has it.

If the game updates and has a problem, remove the mod.
